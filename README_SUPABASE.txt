КАК ЗАПУСТИТЬ БАЗУ (один раз):
1. supabase.com -> твой проект -> SQL Editor -> New query.
2. Открой файл supabase-setup-all.sql, поменяй почту и пароль учителя в блоке «УЧИТЕЛЬ».
3. Скопируй ВЕСЬ файл в окно, нажми Run. Должно быть Success.
4. В supabase-config.js должны стоять адрес и anon-ключ ЭТОГО проекта (Settings -> API).
5. Вход учителя: почта и пароль из шага 2, на странице «Войти».
Ученики: Authentication -> Providers -> Email -> можно выключить «Confirm email», чтобы не подтверждать почту.
